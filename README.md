# Agenda Clan Ingelbrecht

Website op https://gezin.cdrone.be die de Google Agenda "Onbeschikbaarheid Clan Ingelbrecht" toont.

- `index.html` – de pagina (Google Agenda-embed met week/maand/lijst-weergave)
- `CNAME` – eigen domein voor GitHub Pages

Afspraken toevoegen of wijzigen gebeurt gewoon in Google Agenda; de site werkt automatisch bij.
